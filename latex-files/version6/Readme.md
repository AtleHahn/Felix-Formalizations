
# Version 6

This directory contains the version of `formalizations.tex` and `naprochelibrary.tex` obtained
from version 5 after modifying `naprochelibrary.tex` and `formalizations.tex` in the following way:

1. In version 5 the file `naprochelibrary.tex` contained two different notions of natural numbers:

    - von Neumann naturals, and
    - positive real naturals.

   Von Neumann naturals have now been removed from `naprochelibrary.tex`.

2. The file `formalizations.tex` was modified accordingly and it was also extended by Section 50 of Munkres book.

3. The two theorems `zorn_subset_family` and `well_ordering_theorem_local_finiteness`, which formalize versions of
   Zorn's lemma and the well-ordering theorem, were moved to the file `naprochelibrary.tex` 
   and their proofs provided.
   Moreover, the missing proofs in section `Cardinality` in `naprochelibrary.tex` have also been added.

## Terminology

Munkres uses the concept `neighborhood` in a non-standard way.
Many other authors would use the term `open neighborhood` for what
Munkres calls a `neighborhood`.
