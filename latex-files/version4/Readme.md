
# Version 4

This directory contains the version of `formalizations.tex` obtained after 
several rounds of autoformalization, followed by suitable acceleration, proof distillation, and proof
elaboration rounds.

In contrast to version 3, sections §34 - §49 of Munkres' book are now covered in version 4.

*Note:* Section §50 (= the last section on set theoretic topology) is not yet included.
      We plan to include it in version 5 after modifying the file naprochelibrary.tex.
      Currently, there are two versions of the notion of natural numbers in naprochelibrary.tex, namely 
      von Neumann naturals and positive real naturals.
      This led to many very long formal proofs in the current formalized version of §50,
      which is why we decided to omit this section in version 4.
