
# Version 0

This directory contains the original version of `formalizations.tex`,
obtained by formalizing Sections 12 to 33 of Munkres' textbook up to
Urysohn's lemma.

## Remarks

1. Seven proofs are omitted because they are not needed for the proof of
   Urysohn's lemma.
2. These seven gaps are closed in `version3`.
